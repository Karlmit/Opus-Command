## DL-002 — Working Mode: Fast Path
**Decision:** Fast path selected. AI drafts full PRD with [ASSUMPTION] tags; Karl reviews.  
**Source:** Karl, 2026-06-07.

## DL-003 — Users: Single Admin Only
**Decision:** V1 supports a single admin account. No multi-user support.  
**Source:** Karl, 2026-06-07.

## DL-004 — TLS: External via Reverse Proxy
**Decision:** Application listens on plain HTTP port 3000. TLS handled by Nginx Proxy Manager. Public URL: https://opus.jabba.se.  
**Source:** Karl, 2026-06-07.

## DL-005 — Git Snapshot Definition
**Decision:** "Create Snapshot" is implemented as an annotated git tag with format `snapshot/YYYY-MM-DD-HH-MM-SS` plus optional user-provided label in the tag message. Provides a pre-AI-session restore point for all git-tracked files. Karl confirmed date+time format makes sense.  
**Source:** Confirmed by Karl, 2026-06-07.

## DL-006 — Technology Stack
**Decision:** Node.js + Express + React/Vite + SQLite/Drizzle + node-pty + xterm.js + Socket.io + dockerode + simple-git + bcrypt/express-session.  
**Source:** Karl confirmed AI chooses the stack ("You decide. It's an AI project Manager built by AI"). Tagged [ASSUMPTION] in Section 8.

## DL-007 — V1 Notifications: UI Badges + Optional Sound
**Decision:** V1 AI session notifications are: UI badge on project card + badge on terminal tab + optional configurable sound. Browser push notifications (requiring HTTPS + service worker) are out of scope for V1.  
**Source:** Karl, 2026-06-07.

## DL-008 — Distribution: GHCR + GitHub Actions
**Decision:** Docker image published to ghcr.io/karlmit/opus-command. GitHub Actions workflow triggers on push to main and on tagged releases. Multi-arch: amd64 + arm64.  
**Source:** Karl's supplemental spec, 2026-06-07.

## DL-009 — Self-Update: Not in V1
**Decision:** Application detects updates via GitHub Releases API and shows version info in Settings > Updates, but does not perform self-updates. Users update via their Docker management tool (Unraid, Watchtower, Portainer, docker compose).  
**Source:** Karl's supplemental spec ("Opus Command should not perform self-updates in v1"), 2026-06-07.

## DL-010 — Data Persistence Strategy
**Decision:** All user data in /app/data volume. Database is SQLite. Drizzle ORM handles migrations automatically on startup. Container replacement without volume removal is fully non-destructive.  
**Source:** Karl's supplemental spec, 2026-06-07.
