# UX Decision Log — Opus Command

**Workspace:** ux-OpusCommand-2026-06-07
**Created:** 2026-06-07

---

## DL-UX-001 — Color Mode Strategy
**Decision:** Dark and light mode both supported. Dark is the default and primary focus. Light mode is secondary.
**Source:** Karl, 2026-06-07.

## DL-UX-002 — Theme System
**Decision:** User-installable color themes, Obsidian-style. Base themes are dark and light; themes swap the color accent (and possibly surface tones) without changing layout or component structure.
**Source:** Karl, 2026-06-07.

## DL-UX-003 — Dark Mode Character
**Decision:** Discord-like dark — muted mid-grey surfaces, NOT OLED black. Comfortable for extended use.
**Reference:** Discord surface ~#313338, background ~#2B2D31.
**Source:** Karl, 2026-06-07.

## DL-UX-004 — Corner Radius
**Decision:** Soft/rounded corners preferred throughout. Consistent with the circular mark geometry.
**Source:** Karl, 2026-06-07.

## DL-UX-005 — Logo-derived Accent
**Decision:** Primary accent color is #3B82F6 (Tailwind blue-500) — the only chromatic color in the mark. All themes use this as the default accent; installable themes may override it.
**Source:** Logo analysis, 2026-06-07.

## DL-UX-006 — Typography
**Decision:** Inter typeface (already used in the logo wordmark). Consistent with OPUS (400) / COMMAND (600) weight pairing — restrained weight contrast, not decorative.
**Source:** Logo SVG, 2026-06-07.

## DL-UX-007 — Hierarchy Language
**Decision:** Opacity layering as the primary hierarchy signal, derived directly from the logo mark (1.0 → 0.6 → 0.38 → 0.22). Strong/medium/dim text tiers; not color-based hierarchy.
**Source:** Logo analysis, 2026-06-07.

## DL-UX-014 — UX Finalized
**Decision:** UX finalized 2026-06-07. Spines distilled (DESIGN.md + EXPERIENCE.md, both status: final). Three mockups promoted to mockups/: desktop cockpit, mobile status card, mobile terminal view. Karl approved all mockups.
**Mockup coverage:** Desktop cockpit ✅ | Mobile status card ✅ | Mobile terminal ✅ | Login/First Run (spine-only) | Settings (spine-only) | Projects list (spine-only) | File browser (spine-only)
**Source:** Karl, 2026-06-07.

## DL-UX-013 — Mobile Entry Point
**Decision:** On mobile, opening a project lands on a Project Status Card (workspace status, AI session state, git summary, active terminal count) with a prominent "Go to Terminal" button. Not a direct terminal landing — situational awareness first.
**Source:** Karl, 2026-06-07.

## DL-UX-012 — Mobile Layout Strategy
**Decision:** Mobile is a simplified, purpose-built layout — not a scaled-down cockpit. Primary mobile view: project status + terminal interaction. File browsing available but secondary (accessible as a mode/tab). The dense multi-panel desktop layout does not translate to mobile.
**Source:** Karl, 2026-06-07.

## DL-UX-011 — Terminal Font
**Decision:** Geist Mono for terminal content and code. Consistent with the UI typeface family (Geist).
**Source:** Derived from typography decision, 2026-06-07.

## DL-UX-010 — UI Typography
**Decision:** Geist (by Vercel) for all UI text — replaces Inter for the app UI (Inter stays in the logo SVG as baked-in). Geist is the open-source equivalent of xAI's Everett — same clean geometric feel Karl referenced. Light/Regular for body, Medium/Semibold for headings. Generous letter-spacing. No monospace in UI labels outside the terminal.
**Source:** Karl referenced xAI/Grok font language; Geist chosen as equivalent, 2026-06-07.

## DL-UX-009 — Design Direction Selected
**Decision:** Direction 1 — Dense Command Center. Military-grade ruled grid, every metric visible, hairline dividers, monospaced metadata accents. Blue accent (#3B82F6) reserved as a signal color for live AI state only — not decorative.
**Source:** Karl, 2026-06-07.
